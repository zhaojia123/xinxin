# 欣欣的日常记录

这是 `friends-records` 的原生微信小程序，AppID 已配置为 `wx61a14738b3d98047`。

## 在微信开发者工具中打开

1. 选择“导入项目”。
2. 项目目录选择本文件所在的 `miniprogram` 目录，不要选择 Go 项目根目录。
3. AppID 会从 `project.config.json` 自动读取。
4. 本地联调时先启动 Go 服务和 MySQL，在开发者工具的“详情 / 本地设置”中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
5. 开发版默认连接 `http://127.0.0.1:8999`；体验版和正式版连接 `https://xxtaizhang.cn`。真机调试时，可在开发版登录页打开“开发连接设置”覆盖地址。

正式发布前，请在 `config.js` 的 `trial` 和 `release` 中填写已经配置到微信公众平台的 HTTPS 接口地址，并在服务端关闭 `wechat.mock_login`。

## 页面和操作

- 微信登录后默认进入台账列表。
- 底部有“台账”“采购”和“员工管理”三个导航。
- 台账支持开始/结束日期区间、收支类型和关键词查询，支持新增、修改、详情查看及在详情页上传转账凭证图片。
- 采购支持按日期记录供货商、品类、菜品、数量、单位、单价和特殊备注，自动计算行总价和品类合计，可在手机上下载并打开 Excel 采购清单。
- 员工支持状态和关键词查询，支持新增、修改、详情查看及在详情页上传身份证人像面、国徽面、健康证正反面图片。
- 表单内可以创建资金账户、收支分类、部门及岗位。
- 底部导航和服务端接口会按 `mini_user_permissions` 的 `module_key` 过滤。将某用户的 `ledger`、`employees` 设为 0、`purchases` 设为 1 即可让他只看到采购导航；权限变更后重新登录小程序即可生效。
- 后台可在 `/admin/mini-users` 页面直接勾选用户权限，无需手动操作数据库。
- 每个模块可分别控制查看、新增、编辑、删除权限；例如只勾选采购“查看”即可只读采购清单。

小程序登录令牌有效期为 7 天。服务端停用对应 `mini_users` 用户后，已有令牌也会立即失效。
