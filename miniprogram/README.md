# 欣欣的日常记录

这是 `friends-records` 的原生微信小程序，AppID 已配置为 `wx61a14738b3d98047`。

## 在微信开发者工具中打开

1. 选择“导入项目”。
2. 项目目录选择本文件所在的 `miniprogram` 目录，不要选择 Go 项目根目录。
3. AppID 会从 `project.config.json` 自动读取。
4. 本地联调时先启动 Go 服务和 MySQL，在开发者工具的“详情 / 本地设置”中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
5. 模拟器默认连接 `http://127.0.0.1:8999`。真机调试时，在登录页打开“开发连接设置”，改为电脑局域网地址，例如 `http://192.168.1.8:8999`。

正式发布前，请在 `config.js` 的 `trial` 和 `release` 中填写已经配置到微信公众平台的 HTTPS 接口地址，并在服务端关闭 `wechat.mock_login`。

## 页面和操作

- 微信登录后默认进入台账列表。
- 底部只有“台账”和“员工”两个导航。
- 台账支持按月、收支类型和关键词查询，支持新增及修改。
- 员工支持状态和关键词查询，支持新增及修改。
- 表单内可以创建资金账户、收支分类、部门及岗位。

小程序登录令牌有效期为 7 天。服务端停用对应 `mini_users` 用户后，已有令牌也会立即失效。
