# 欣欣的日常记录

这是 `friends-records` 的原生微信小程序，AppID 已配置为 `wx61a14738b3d98047`。

## 在微信开发者工具中打开

1. 选择“导入项目”。
2. 项目目录选择本文件所在的 `miniprogram` 目录，不要选择 Go 项目根目录。
3. AppID 会从 `project.config.json` 自动读取。
4. 本地联调时先启动 Go 服务和 MySQL，在开发者工具的“详情 / 本地设置”中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
5. 开发版默认连接本机 `http://127.0.0.1:8999`，体验版和正式版固定连接 `https://xxtaizhang.cn`。

正式发布前，请在微信公众平台的「开发管理 / 开发设置 / 服务器域名」中配置 `https://xxtaizhang.cn`，并确认服务器的 `config.toml` 使用生产配置：`app.env = "production"`、`wechat.mock_login = false`，以及可写入的绝对上传目录。`config.example.toml` 已提供对应模板；请只在服务器的实际配置中填写密钥和数据库连接信息。

## 页面和操作

- 微信登录后默认进入员工档案。
- 底部仅显示“员工档案”和“请假管理”两个导航；没有对应权限的导航不会显示。
- 员工档案支持正式工、临时工的切换、查询、新增、修改、详情与删除；新增时员工编号自动生成，入职日期默认当天。
- 请假管理只面向正式工，支持公休、请假、法定节假日与特殊请假补贴的登记、修改和删除。
- 底部导航和服务端接口会按 `mini_user_permissions` 的 `module_key` 过滤。权限变更后重新登录小程序即可生效。
- 后台可在 `/admin/mini-users` 页面直接勾选用户权限，无需手动操作数据库。
- 每个模块可分别控制查看、新增、编辑、删除权限；例如只勾选员工档案“查看”即可只读员工资料。

小程序登录令牌有效期为 7 天。服务端停用对应 `mini_users` 用户后，已有令牌也会立即失效。
